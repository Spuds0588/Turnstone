# Sample link queue

The same 10 tasks as `sample-links.csv`, written as a GitHub-style task list — the
shape a queue usually lives in once it is kept in a README. Nothing outside the list
should be imported: prose [like this link](https://example.com/prose-is-not-a-task)
is not a task, and neither is a link inside a fence:

```
https://example.com/in-a-code-fence
```

Checkbox state becomes each card's status, the text before the link becomes the task
name, and whatever follows it becomes the note.

- [ ] Apple Newsroom — https://www.apple.com/newsroom/ — Q3 earnings page
- [x] BBC Homepage — https://www.bbc.com/
- [ ] Changelog Nightly — https://changelog.com/nightly — Skip the archive pages
- [x] Comma, Inc. Blog — https://example.com/comma-blog — Note with, commas, and "quotes"
- [ ] Demo Domain — https://example.com/
- [ ] GitHub Trending — https://github.com/trending — Check weekly
- [x] Hacker News — https://news.ycombinator.com/ — Blocked in iframes — use ↗
- [ ] Sheets Example — https://example.com/sheet-demo
- [ ] Turnstone Repo — https://github.com/
