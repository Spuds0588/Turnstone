Your list, worked through.

Turn your list of links into a work queue: track status & notes, open each link the way you like — tabs, browser tabs, or popup windows — and auto-save back to the file (Chromium) or browser storage.

⤓ Drop a file here, or click to choose Read and parsed on this device — nothing is uploaded. CSV · TSV · XLSX / XLS / ODS · DOCX · Email (.eml) · Markdown · JSON · HTML · XML

No file to hand? Copy a table anywhere — a portal, a mail client, a spreadsheet — and press Ctrl+V (⌘+V) anywhere in Turnstone.

A public link-list URL works here (its host must allow CORS) — and so does a shared link, one that already carries the list inside it, which fetches nothing at all. Deep links: ?file=<url>, ?url=<url>, #zdata=…; add &open=1 to auto-open the first task.

Columns

Order, name, role and visibility. Drag a row by ⋮⋮ to move a column, untick it to take it off the cards, and type over its name to rename it — the name is the file's header cell, so a rename is written back when you export. The role dropdown says what a column is: Turnstone picks the link column from the values themselves — a page, an @address or a phone number all count — so if it ever guesses wrong, or your links are bare example.com, set URL here and it sticks for this file. Addresses and numbers anywhere on a card stay clickable on their own, through MailLayer and PhoneLayer.

Editing. The last dropdown gives a column a control on every card — a short or a long text field, a dropdown, or a row of buttons — for the columns you update as you work. A dropdown's choices start from the column's own values (the ↧ button) and are yours to edit after that; whatever you type into a cell is written into that row, and leaves with the file on export. Columns marked card feature already have a control of their own.

Portal link template optional

For lists where nothing in the file is a link because the work happens in one portal. Name the portal address and every card gets a link built from its own row — {Column name} is replaced with that cell's value. Remembered for this column layout, and shareable with ?link=. Leave it empty and cards link to the file's own URL column, as before.

Save the layout as a preset — any link list whose header row matches this exact column order loads with it pre-applied.

Turnstone is a desktop app

Mobile isn't supported. Open Turnstone on a desktop — or on a device and window sized like one.

This device reports a touch-first pointer at 0×0px. On touch, file picking, drag-and-drop and save-back are unreliable — expect a broken workspace.
