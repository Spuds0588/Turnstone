What to check once it is running
1. The window is taken over by Turnstone, with a thin bar at the top: Turnstone · the variant name · Copy state / Restore state / ✕ Close.
2. Demo list loads 5 cards — the app's built-in dataset, no file needed.
3. Drop a real .csv / .xlsx anywhere on the page: it loads, cards render, ✓ Complete and notes work.
4. Copy state → ✕ Close → click the bookmarklet again → Restore state → paste: statuses and notes come back.
5. ✕ Close returns the page exactly as it was (no leftover styles, no globals).
