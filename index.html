Turnstone loads the link list you already keep — spreadsheet, CSV, JSON or HTML — prospects, listings, docs to review, outreach to send — and turns it into a modern split-pane workspace: task cards with statuses and notes on one side, the links themselves in a tabbed pane on the other. Progress saves straight back to your file. It runs entirely in your browser, so there's no backend to buy, no seat licenses, and nothing to sign up for.

From spreadsheet to workspace in one step

Three ways in — pick whichever your file is closest to.

1

Drop your file

Drag a CSV, TSV, XLSX, JSON, HTML or XML list onto the app — anywhere on it — or click the drop area to pick the file from disk. Across the whole app, Chromium browsers get silent auto-save write-back to the original file.

2

Or point at a URL

Give Turnstone a web address to a spreadsheet and it loads it on arrival — shareable as a link.

app.html?file=https://example.com/queue.csv
3

Work the queue

Cards down one side, pages across the other. Complete, note, auto-advance — then export or auto-save when you're done.

Questions, answered

The things people check before trusting an app with their list.

Does Turnstone upload my spreadsheet anywhere?

No. Turnstone is a zero-backend application: parsing, tracking, and saving all happen in your browser, and your file is written back to your own disk. Nothing is uploaded to any server — you can watch the network tab stay quiet.

What file formats does it support?

CSV, TSV, XLSX, JSON, HTML tables and XML feeds. Any column named URL or Link is treated as the link to open; every other column is carried onto the card. Statuses and notes you enter are saved back into the file (or exported if your browser can't write back).

Can I pick up where I left off?

Yes. Reload the same file — or a list you exported from Turnstone — and its completed and notes columns are read back onto the task cards, so the queue continues exactly where it stopped. The completed column is recognised by name (Status, Completed, Done, Finished, Checked, …) as well as by its values (complete, done, yes, 1, a tick, or a completion date).

Is it really free?

Yes — open source, no accounts, no signup, no seat licenses. The whole product runs on your machine; there are no server costs to recover.

Can I install it as a desktop app?

Yes. Turnstone is a PWA — install it from your browser to get a standalone window and offline access to the app shell, with your queue reloadable from your last file.

Some sites refuse to load in the tabbed pane. Why?

A few sites send headers that forbid being framed by any web app — that's a browser security rule, not a Turnstone limitation. For those, switch the open mode to new browser tab or popup window in the ☰ menu; the native desktop version on the roadmap removes the restriction entirely.

What's on the roadmap?

Bookmarklet, browser-extension, and native desktop editions that share the same core — see the repository for the current plan and status.
