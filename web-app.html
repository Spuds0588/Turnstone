Web app Start here

The canonical edition, and the one to try first. It is the full experience — the only one with the split-pane layout where the links themselves render beside the queue — and it is the only one that both remembers your progress and writes it silently back into your file.

▶ Launch the web app See it with a sample queue

Who it is for

  • Almost everyone, almost always. A normal desktop or laptop, a browser that is not locked down, and a link list you own — this is the edition that does the most with the least effort.
  • Anyone who wants their progress to exist tomorrow. Statuses, notes, recent files, column presets, open mode and theme all persist locally between visits.
  • Anyone whose list arrives as a real spreadsheet. It takes CSV, TSV, XLSX/XLS/XLSM/XLSB/ODS, JSON, HTML tables and XML feeds, and it writes back to CSV, TSV and XLSX.
  • Chromium users who want write-back with no save button. Once you have picked a file, edits are written straight into it as you work.

What it does

  • Every input format: CSV, TSV, XLSX/XLS/XLSM/XLSB/ODS, JSON, HTML tables and XML feeds. A PDF is detected and refused with the reason rather than mangled.
  • Silent write-back to CSV/TSV/XLSX in Chromium (File System Access API). Elsewhere: exports plus a browser-storage snapshot, so nothing is lost.
  • Installable as a PWA, and it works offline from the service-worker cache after the first visit.
  • Remembers: recent files, statuses, notes, column presets, open mode and theme.
  • Round-trips an exported queue: re-import a file Turnstone wrote and the notes and completed states come back, so a queue can be worked in two sittings or handed to someone else.

What it does not do

  • Reach a site that refuses to be framed. A page sending X-Frame-Options or a restrictive frame-ancestors cannot render in the workspace. Turnstone detects it and says so; use New browser tab mode for those links, or the extension, which never frames anything.
  • Load a list from a server without CORS. ?file= needs the host to send CORS headers. Local files and drops are unaffected.
  • Work with no network at all on first visit. After that the cache covers it — or use the standalone build, which never needs a network in the first place.
  • Write back on a browser without the File System Access API. Firefox and Safari get the app's export path instead of live write-back — everything else works the same.

Install it as an app

1

Open the web app in Chrome, Edge or another Chromium browser.

2

Use the install icon in the address bar, or ☰ → Install app. It appears in the ☰ menu only once the browser has offered it.

3

Launch it from your apps menu like any other application. It opens in its own window and works offline.

On a machine where nothing may be installed, this step is the one to skip — take the standalone build or the bookmarklet instead.
