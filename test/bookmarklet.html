Turnstone — bookmarklet variant sweep

The bookmarklet is the one edition that cannot be swept like the others: it has no URL of its own, no reachable internals, and it mounts into a page it does not own. So this is the closest thing to production there is — each variant is fetched from dist/, its javascript: URL is decoded exactly as a browser decodes a bookmark, and the payload is evaluated inside a throwaway page. From then on nothing is stubbed: files arrive through the real drop path as real File objects, and every assertion reads the overlay's own rendered DOM.

What each variant promises is not guessed here — it is asserted against the claim the app itself prints in its capability notice, so a payload that quietly loses DOCX or a workbook reader fails rather than shrinks.
