Chrome extension Available

Overview› All versions› Chrome extension

A Manifest V3 extension whose whole UX is Chrome's side panel: the same task queue, pinned beside whatever you are reading. There are no iframes in this edition at all — links open as real browser tabs, and selecting a card switches the browser to that card's tab. The queue drives the browser instead of hosting it.

Who it is for

  • Anyone who works through links while reading something else. The panel stays beside the page, and the badge keeps counting down with the panel shut.
  • Anyone who hates losing a tab. Clicking a card twice never opens a second copy of the same page — it switches back to the tab the row already owns.
  • People on sites that refuse to be framed. This is the edition with no framing at all, so X-Frame-Options is beside the point.
  • Anyone who wants the queue to outlive a closed panel — statuses, notes, presets and the open file persist per browser, which the bookmarklet cannot do by design.

What it does

  • Links become real browser tabs, and the panel remembers which tab belongs to which row. Completing a card auto-advances to the next tab.
  • The toolbar badge shows tasks left, so the count is visible without the panel.
  • Right-click → “Add link to Turnstone” on any link, on any page. It appends to the open queue, starts one if there is none, or waits for the panel to next open if it was shut.
  • The same sidebar the web app has: cards, ✓ Complete / ↺ Incomplete, notes, search, sorting, column presets, exports, and the file-round-trip resume.
  • Real write-back when you pick a file (Chromium), same as the web app — and exports land in your Downloads folder through the browser's own download API.

What it does not do

  • Frame pages. A side panel is about 360 px of browser chrome, not a viewport, so this is the one edition with no tabbed workspace. When you want the pages themselves rendered beside the queue, use the web app.
  • Run in Firefox or Safari. Manifest V3 with the Side Panel API is Chromium-only (Chrome 114+, Edge). Use the standalone build or the web app there.
  • Install in one click. It is not on the Chrome Web Store yet, and Chrome only loads extensions unpacked in Developer mode or from the store.
  • Bulk-import a whole site. It queues links one at a time, as you right-click them. It does not crawl a page looking for links — feed it a CSV/XLSX export instead.

Install it — load unpacked

1

Get the folder: clone the repo, or download it as a ZIP and unzip. The extension is ports/extension/dist.

2

Open chrome://extensions and turn on Developer mode (top right).

3

Click Load unpacked and choose the ports/extension/dist folder. Turnstone appears in the toolbar.

4

Click the toolbar icon — the queue opens in the side panel, on the drop-zone screen. Or right-click any link on any page and choose Add link to Turnstone.

Build: v0.1.0 · Manifest V3 · needs Chromium 114+ · 13 files of its own, 1.08 MB installed.

Regenerate the folder after any change to the app with node ports/extension/build.js. The build refuses to emit a panel that has drifted from app.html: it patches the app's own stylesheet, markup and script and asserts every anchor, so a change upstream fails the build instead of shipping a broken side panel.

Permissions

It asks for five and no host access: sidePanel, tabs, storage, downloads and contextMenus. It cannot read or modify the pages you visit — the context-menu item is the only way it touches one, and then only to take the link you right-clicked.
